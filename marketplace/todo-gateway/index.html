Todo Gateway

Manage a user's daily to-do list through a secure internal gateway.

Lets the assistant list the day's tasks, review what is unfinished, and mark tasks as checked through an internal gateway API. Calls go through Curl Request against the configured GATEWAY_HOST.

Read when

  • asked about unchecked tasks of the day
  • asked to 'check' some specific task
  • asked to review today's priorities
